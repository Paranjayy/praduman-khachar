# DESIGN.md — Visual Direction & Design System

## 🏛️ Brand Persona & Palette
- **Primary Canvas:** Warm Ivory / Parchment (`#FAF7F2`)
- **Dark Chrome / Accent:** Dark Ink (`#2C2418`)
- **Accent Terracotta:** Warm Earth (`#C05A3E`)
- **Accent Muted Gold:** Antique Brass (`#C5A55A`)
- **Typography:** Serif for headings (scholarly, editorial) paired with clean geometric/humanist Sans for UI elements.

## 📐 Layout & Spacing
- Restrained grid layout with ample whitespace.
- Extractable 40-60 word summaries at the start of key sections for AEO.
- High accessibility contrast ratio (WCAG AA minimum).
